# 🚀 Getting Started with Your React App

This project was created using Create React App, a tool that helps you quickly set up a modern React application with zero configuration.

---

## 📖 About the Project

GourmetList is a simple and practical shopping list app designed for everyday use. It helps you keep track of what you need to buy and makes it easy to share your list with a flatmate, or partner, so you can both stay organised and avoid duplicate purchases.

## 📲 Installable App

This app is installable as a Progressive Web App (PWA).

* On supported browsers, you can add it to your home screen or desktop.
* It behaves like a native app with its own icon and standalone window.
* Some features may also work offline depending on caching.
